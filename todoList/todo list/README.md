# Todo List App

A clean, simple, and responsive Todo List application built with React. The app allows users to manage their daily tasks with a user-friendly interface.

# Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Responsive design for mobile and desktop
- Clean and simple user interface
- Tasks are saved using LocalStorage
- Data remains available even after refreshing or reopening the browser
- Interactive UI with Material UI components and icons

# Technologies Used

- React
- Vite
- JavaScript
- Tailwind CSS
- Material UI (MUI)
- Material UI Icons
