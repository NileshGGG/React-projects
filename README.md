## 🍔 Featured Project: NG Restaurant App

A high-performance Food Delivery Single Page Application built with **React 19**, **Tailwind CSS**, **Material UI**, and **Parcel**.

### Key Highlights
- **Global Cart State:** Powered by custom React Context with immutable array CRUD operations.
- **Smart Free Delivery:** Orders ₹200 and above unlock free delivery with dynamic threshold nudging.
- **Instant Search & Multi-Filters:** Instant live search paired with multi-criteria filter chips (Pure Veg, 4.0+ Rating, Fast Delivery).
- **Deep Routing:** Dynamic `/restaurants/:resId` pages with menu sections and dietary indicators.
- **Zero-Config Tooling:** Blazing fast development using Parcel 2 and PostCSS.

### Quick Start (NG Restaurant)

```bash
cd restaurant
npm install
npm start
```
Runs the development server at `http://localhost:1234`.
